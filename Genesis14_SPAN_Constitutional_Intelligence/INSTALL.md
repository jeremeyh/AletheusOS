# Installation Placement

1. Download and unzip the release.
2. Move the entire extracted folder into the AletheusOS repository root.
3. Open Terminal in the AletheusOS root.
4. Activate `.venv`.
5. Run `install.sh`.

Example:

```bash
cd ~/Development/AletheusOS
source .venv/bin/activate
chmod +x Genesis14_SPAN_Constitutional_Intelligence/*.sh
./Genesis14_SPAN_Constitutional_Intelligence/install.sh
```

The package is an overlay release. Do not manually drag individual source
files into the repository.
