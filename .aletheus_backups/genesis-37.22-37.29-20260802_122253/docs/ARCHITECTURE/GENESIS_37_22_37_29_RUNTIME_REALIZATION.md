## Mathematical Runtime

The package implements evidence mass, consensus pressure, contradiction shear, temporal momentum, second-order spring dynamics, and Poincaré-ball distance/projection.

## Founder Isolation

Founder Observatory remains a separate, root-attested runtime. Workspace Composer rejects Founder-only instruments. No public extension surface is declared.

## Production Qualification

The installer attempts real Cargo, wasm-pack, and TypeScript builds on the target machine. A build failure stops installation unless the operator explicitly sets `ALETHEUS_ALLOW_PARTIAL_GENESIS37=1`. This prevents uncompiled placeholders from receiving runtime certification.
