# Genesis 14.0 — SPAN Constitutional Intelligence™

Genesis 14 transforms the completed Genesis 13 SPAN infrastructure into a
usable constitutional analysis capability.

It adds:

- 20 deterministic rules across 10 canonical families
- project inspection and evidence collection
- constitutional, strict, advisory, and CI profiles
- JSON and Markdown reporting
- the canonical `SPAN().analyze(...)` developer API

This release intentionally adds no new registry, loader, runtime, or engine.
It composes the Genesis 13 contracts.
