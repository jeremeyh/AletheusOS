# Cognitive Kernel™

**Genesis:** 46.1

**Version:** 1.0.0 RC1

---

# Purpose

The Cognitive Kernel™ is the constitutional orchestration layer of AletheusOS.

It does **not** perform reasoning.

It does **not** appraise.

It does **not** deliberate.

It coordinates governed cognition throughout the Foundation.

Every request entering the Foundation first passes through the Cognitive Kernel.

# Non-Responsibilities

The Cognitive Kernel is **not** responsible for:

- Authentication
- Identity resolution
- Marketplace intelligence
- Portfolio analysis
- Reasoning
- Council deliberation
- Memory persistence
- Forecasting
- Application logic

Those responsibilities belong to other Foundation capabilities.
