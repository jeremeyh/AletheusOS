# AletheusOS Canonical Identity

| Name | Canonical role |
|---|---|
| AletheusOS | Platform and operating environment |
| Aletheus Runtime | Canonical Python runtime kernel |
| CardHawk | First product application and collectible-intelligence domain |
| Nimble | Frontend and experience shell |
| Genesis | Historical release and migration label only |

The only canonical platform runtime is `aletheus.runtime.AletheusRuntime` and its process-wide instance `aletheus.runtime.runtime_core`.
