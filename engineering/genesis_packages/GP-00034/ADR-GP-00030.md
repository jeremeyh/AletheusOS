# ADR-GP-00030 — Genesis Platform Constructor

Status: Proposed  
Classification: ADDITIVE  
Authority: Genesis™  

## Decision

Add Genesis as the platform constructor responsible for producing conformant Genesis Packages.

## Rationale

AletheusOS needs a repeatable package construction workflow that is ontology-aware, ADR-ready, collision-checkable, and Repository DNA-recordable.

## Consequences

Future work should increasingly be delivered as Genesis Packages.
