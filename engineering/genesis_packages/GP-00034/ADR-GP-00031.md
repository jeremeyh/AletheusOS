# ADR-GP-00031 — Atlas Authority Core

Status: Proposed  
Classification: ADDITIVE  
Authority: Atlas™  

## Decision

Add Atlas as the first operational Sovereign Authority responsible for architecture knowledge.

## Rationale

AletheusOS needs a living architecture graph so the Super-Mesh can be understood, validated, visualized, and governed.

## Boundary

Atlas knows architecture. It does not govern, execute, predict, or defend.
